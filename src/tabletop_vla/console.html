    Experimental learned AI

    A trained ACT policy observes the overview camera and robot joint positions, then predicts motor actions. OpenVINO runs the model locally. This is a single-cup experiment, not the full bimanual challenge.

    Checking the local model…

    Safe finish adds a scripted upward retreat and settling time after the learned actions. It is a hybrid controller, not a pure learned-policy result. Neither mode uses a VLM planner.

    What is MuJoCo?

    MuJoCo is the physics engine behind this scene. Joint motors move the arms; objects fall under gravity; touching shapes generate contact forces. The browser displays camera frames from the simulator and sends your controls back to it.

    Visit the official MuJoCo website ↗

    Robot controls

    Move a slider and the motor starts following it automatically. Manual controls interrupt the arm demo. Values show actual → target in radians.

    New environment

    Changes placement, mass, friction, lighting, cup proportions, and table/floor colors. The same seed recreates the same starting state. Arbitrary shapes and clutter are not covered.

    Reach diagnostic

    Move the selected tip 3 cm upward. A reachable target starts motor movement automatically. Position-only IK; grasp orientation and path collision avoidance are not implemented yet.
